##### 统一学习心得总结

6.1 随机密码生成

练习了 string 字符集常量与 random.choice() 随机采样。字符串属于序列类型，可以用生成式快速拼接。这道题直观理解：密码本质就是从一个字符集合中随机抽取元素组合。

6.2 重复元素判定（遍历版）

采用临时列表记录已经访问过的元素，逐个比对查重。思路易懂，但时间复杂度较高，数据量大时效率差，适合理解查重底层逻辑，也为集合优化方案做铺垫。

6.3 重复元素判定（集合版）

利用集合元素唯一、自动去重的核心特性，对比集合与原列表长度就能判断重复。代码简洁，底层哈希查找，查询速度远高于顺序遍历。通过两题对比，体会到集合天然适合去重、成员判断场景。

6.4 文字字符分析

字典是典型的映射结构，非常适合频次统计：key 存储字符，value 存储计数。dict.get() 是词频统计经典写法，配合 sorted() + lambda 自定义排序规则。测试中英文文本后发现：英文字母频率分布有稳定规律，中文单字高频大多是助词。

6.5 生日悖论模拟

继续使用集合快速查重，遇到重复生日可以提前跳出循环，节约计算资源。生日悖论结果反直觉：23 人时相同生日概率接近 50%。这是蒙特卡洛模拟思想，模拟样本数量越大，结果越逼近理论值。

6.6 《红楼梦》人物统计

综合运用 jieba 分词、字典计数、停用词过滤、别名合并。直接分词会混入大量虚词干扰排名，需要人工构建停用词表、统一人物别称。是序列、映射、中文分词的综合性实战，也是后续武侠文本分析的基础模板。

6.7 《天龙八部》常用词统计

流程和红楼梦统计一致，不再限定人名，只过滤单字。可以观察到武侠小说高频词汇多为动作、称谓、武功相关词语。固化了中文文本分析标准流程：读取文本 → 分词 → 过滤无效词 → 字典统计 → 排序输出。

6.8 金庸写作风格分析

将词频统计逻辑封装成函数，消除重复代码，方便批量处理多部小说。横向对比三部作品高频词，可以看出金庸写作共性：高频词集中在江湖、内力、招式、人物称谓；不同作品侧重点又各有区别。这一题把组合数据类型、函数封装、文本挖掘融合在一起。



##### 本章整体知识点复盘

列表：有序、可变序列，适合顺序存储；

集合：无序、元素不可重复，主打去重、成员判断；

字典：键值映射结构，最适合计数、词频统计；

jieba 库：中文分词，区分迭代器与列表；

学会简单文本挖掘思路与蒙特卡洛模拟思想。
